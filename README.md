A responsive, dependency-free recreation of the screen-recorded demo.

## Included effects
- Liquid Fill
- Neon Border Draw
- Magnetic Glow (pointer-following highlight and magnetic movement)
- Clip-path Wipe
- 3D Isometric (hover and pressed depth)

## Run
Open `index.html` in a modern browser, or run:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000.

## Source fidelity
The supplied recording shows a browser demo titled “Advanced Button Animations” with five tabs and CSS snippets. The project reproduces that structure and the five visible effects. Some small code text in the recording is not sufficiently legible to guarantee character-for-character transcription; the included CSS is a runnable reconstruction of the demonstrated effects, not a claim that the original author's complete source was recovered.
